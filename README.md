# Пользовательская документация по эксплуатации ИС (Вариант 22)

## 1. Краткое описание программы
Разработанный программный комплекс представляет собой специализированную консольно-графическую систему на языке Python, предназначенную для высокоточного моделирования и прогнозирования объемов дискового пространства и транзакционной нагрузки на серверное оборудование. Приложение позволяет в автоматическом или интерактивном режиме вычислять значения членов арифметических и геометрических прогрессий на основе введенных пользователем начальных параметров последовательностей. Программа оснащена автономной подсистемой администрирования, которая обеспечивает надежную сериализацию конфигурационных профилей и реализует алгоритмы их регулярного резервного копирования и аварийного восстановления при сбоях ИС.

## Задание
* Разработка консольно-графического ПО для нахождения значения n-го члена арифметической или геометрической прогрессии по введенным пользователем первому члену, шагу (знаменателю) и номеру элемента.
* Создание автономного алгоритма резервного копирования и восстановления профилей математических последовательностей для обеспечения отказоустойчивости ИС (ПМ 06).
* Составление сопутствующей технической документации и проведение верификационных тестов.

## Технологии
* Python 3.8+ — Основной язык программирования
* Tkinter — Графический интерфейс пользователя (GUI)
* JSON — Текстовый формат обмена и хранения профилей параметров
* Shutil и OS — Модули сопровождения, бэкапа и работы с файловой системой
* Unittest — Фреймворк автоматизированного тестирования модулей

## 2. Гайд по установке

### Системные требования:
* Операционная система: Windows 10/11, macOS или дистрибутивы Linux.
* Интерпретатор: Среда выполнения Python версии 3.8 или выше.
* Права доступа: Разрешение на запись файлов в целевую директорию проекта.

### Пошаговый процесс установки:
1. Скачайте три исходных файла программного кода (ispolnitelnie.py, graficheskie.py, functionalnie.py) с репозитория.
2. Поместите все три файла в одну общую рабочую папку на диске компьютера (рекомендуется использовать путь без русских букв и пробелов в названии, например: C:\praktika\).
3. Откройте терминал или командную строку Windows в созданной директории с файлами.
4. Убедитесь, что интерпретатор Python доступен в системе, выполнив команду:
   ```bash
   python --version
   ```
   Дополнительная установка сторонних библиотек и пакетов не требуется.

## 3. Гайд по использованию

### Запуск программного комплекса:
Для инициализации ИС выполните в терминале команду запуска главного исполнительного модуля:
```bash
python ispolnitelnie.py
```
На экране откроется графическое окно приложения. При необходимости в правом верхнем углу вы можете переключить язык интерфейса через выпадающий список (RU/EN).

### Интерактивный расчет в графическом окне:
1. Выберите переключатель типа прогрессии (Арифметическая или Геометрическая).
2. Введите числовые значения параметров в соответствующие поля формы:
   * Первый член (a1/b1) — стартовый объем или уровень нагрузки.
   * Шаг или знаменатель (d/q) — интенсивность изменения данных.
   * Номер элемента (n) — глубина прогнозирования (целое число больше 0).
3. Нажмите кнопку «Рассчитать» для мгновенного вывода итогового значения в поле результатов.
4. Нажмите кнопку «Сохранить профиль», чтобы записать текущие параметры в энергонезависимую локальную базу данных для повторного использования.

### Пакетный режим обработки файлов JSON:
1. Нажмите кнопку «Пакетный расчет файла».
2. В открывшемся системном проводнике выберите входной файл настроек параметров (например, input.json).
3. В следующем окне укажите путь и имя файла для сохранения результатов (например, output.json). Вычисления пройдут в автоматическом фоновом режиме.

### Административный регламент сопровождения (Бэкап):
* Создание точки восстановления: Нажмите кнопку «Создать резервную копию (Бэкап)». Подсистема автоматически скопирует базу данных профилей в изолированный каталог backups/ под уникальным штампом даты и времени.
* Аварийный откат: При случайном удалении или повреждении рабочей конфигурации нажмите кнопку «Восстановить из бэкапа». Система самостоятельно найдет последний свежий архив и вернет ИС к стабильному состоянию.
